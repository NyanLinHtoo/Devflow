# DevFlow — Deferred Features

The items below are intentionally deferred and are **not part of the current implementation**. They are recorded here to keep the present scope focused while making the next improvements easy to prioritize.

## Authentication & Security

- [ ] **Forgot password** — Allow users to request a secure password-reset flow.
- [ ] **Email verification** — Verify ownership of an email address after registration.
- [ ] **Social login** — Support sign-in through external identity providers.
- [ ] **Remember me** — Offer an optional longer-lived sign-in session.
- [ ] **Password visibility toggle** — Let users show or hide password input safely.
- [ ] **Refresh-token rotation (v2)** — Rotate refresh tokens to strengthen session security.
